## Использование презентации

### При защите ВКР

**Регламент:** 15–20 минут на доклад + 5–10 минут на вопросы.

**Рекомендуемые акценты:**

- Слайды **1–4** — быстро (~2 минуты): представление, проблема, решение, размер рынка
- Слайды **5–8** — средне (~4 минуты): конкуренты, тарифы, экономика, финмодель
- Слайды **9–13** — детально (~7 минут): архитектура, поток, стек, ход разработки, масштабирование
- Слайды **14–16** — средне (~3 минуты): риски, дорожная карта, компетенции
- Слайды **17–18** — быстро (~2 минуты): UX, заключение, переход к Q&A

Рецензент Кобылкин Н.Н. получает:
- `presentation.pdf` — для предварительного ознакомления
- Доступ к репозиторию GitHub — для глубокого изучения

Подробные ответы на возможные вопросы рецензента — в документах:

## Видео-демонстрация продукта

Параллельно с презентацией для защиты подготовлено видео-демо PlotFinder MVP — полный цикл работы пользователя с продуктом:

1. Открытие сервиса в браузере
2. Ввод тестового кадастрового номера `39:05:030615:27`
3. Получение геометрии участка на карте Leaflet
4. Опциональная загрузка PDF выписки ЕГРН
5. Запуск AI-анализа через Qwen3-32B
6. Демонстрация результата: цветной риск-профиль + список рисков и рекомендаций

**Длительность:** ~3 минуты.

> **Файл видео не размещается в репозитории GitHub из-за ограничения на размер файлов.** Ссылка на YouTube/Vimeo будет добавлена в корневой `README.md` после загрузки.
